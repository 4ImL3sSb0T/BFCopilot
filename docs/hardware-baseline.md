## 5. 阻断项（Blocker）

以下情况出现时**停止电池动力测试**，仅继续断电验证与纯软件工作，禁止以“会用软件
保护”为由继续上电：

- 实物 ADC 满电过压或读数不可区分；
- 电源不稳定或载流能力不足；
- 舵机电源/信号连接未确认。

## 6. 安全规则

- 首次测试拆下连杆或使用限位工装，**禁止带翅膀通电**。
- 上电永远锁定；未标定前禁止带翼解锁（固件已强制）。
- 当前板**没有舵机电源 MOS 控制**：停止 PWM 不等于断电。状态上报 `NO_POWER_CUTOFF`。
